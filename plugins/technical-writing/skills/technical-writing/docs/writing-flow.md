# ドキュメント作成の流れ

## 1. 必要な情報を収集する

### 目的と読者を確認する

- 読者に理解してほしい内容を明確にする。
- 読後に期待する行動を明確にする。
- 対象読者と、その知識レベルを確認する。
- 指定のフォーマットと出力先を確認する。

### 根拠を集める

- 目的に必要な情報を集める。
- コードや公式資料などの一次ソースで裏付けを取る。
- 情報と、その根拠となる参照先を対応付けて控える。
- 推測や未確認の情報は採用せず、根拠を確認する。
- 内容を決めるために必要な不明点は、ユーザーに質問する。

## 2. 情報を整理し、構造化する

### 情報の関係を整理する

- 目的に関係する情報を選ぶ。
- 同じ内容の情報をまとめ、重複をなくす。
- 関連する情報をグループに分ける。
- 情報の親子関係を整理する。
  - 主張と、それを支える事実を対応付ける。
  - 抽象的な概念と、具体例を対応付ける。
- 各グループの根拠を、一次ソースで確認できる状態にする。

### ロジックツリー

下書きとして、情報の関係をツリーで整理する。
同じ情報を複数の枝に重複して置かない。
このツリーを基に、見出しと説明の順序を決める。

```markdown
- 主題
  - ポイントA
    - 根拠となる事実と参照先
    - 具体例
  - ポイントB
    - 根拠となる事実と参照先
```

ツリーは構成を考えるために使う。
最終出力は、指定の形式と読者の目的に合わせて組み立てる。

## 3. 文書を作成し、出力する

### 本文を書く

- 指定のフォーマットに沿って、見出しを配置する。
- 構造化した情報を、読者が理解しやすい順に書く。
- 主張の根拠を確認できるよう、必要な箇所に参照先を示す。
- 推測や未確認の情報を、説明の本文に含めない。
- 解消できない不明点は、本文と分けて確認事項として示す。

### 推敲して出力する

- [文章と構造の指針](../SKILL.md)に沿って推敲する。
- 目的に必要な情報がそろっているか確認する。
- 読者が次に取る行動を判断できるか確認する。
- 指定のフォーマットと出力先に合わせて、文書を出力する。
